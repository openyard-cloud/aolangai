aolangai

Privacy policy

Last updated: 19 November 2026

aolangai is a macOS app and a command, aolangai, that run on your Mac. This page lists what they read and write there, what leaves your Mac, and what this website does.

What the app and the command keep

  • The data store, ~/Library/Application Support/aolangai/aolangai.db (or the path in AOLANGAI_DB): your accounts, the history of delegated runs, and the settings. The same folder holds profiles/, the config dirs of accounts created with let the app create its own folder (auto); window-state.json, the window's size and position; quota-probe/, an empty folder used as the working folder when the app asks for quota; and Electron's own files.
  • The skill, skills/aolangai/SKILL.md, in ~/.claude and in the config dir of each account that has its own.
  • The command, ~/.local/bin/aolangai, a small shell script that runs the command's code inside aolangai.app (or, when installed from source, in the repository).

A skill or command file that aolangai did not create (it lacks the marker aolangai-managed) is never overwritten.

What it reads in a Claude config dir

Only two things: settings.json, which it opens in your editor when you ask, and its own skill file. It reads nothing else there, does not touch the Keychain, and never reads, stores or forwards a login token. Logging in goes through Claude's own claude auth login.

What it reads from other programs

  • Every 10 seconds the app lists the processes on your Mac with ps (process id, parent, user, terminal, start time, executable path), to find open sessions and the app that hosts each one, and keeps only the Claude Code processes of your macOS user. Claude Code installed with npm can run under the name node, so for your own node processes the app also reads the command line with ps; it looks only at the program and its first argument, to tell whether the process is Claude Code, and uses, stores and logs nothing else of it. To show each session on the right account, it reads the environment of those processes with ps and uses exactly one value from it, CLAUDE_CONFIG_DIR, a folder path. For ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN and CLAUDE_CODE_OAUTH_TOKEN it only looks at whether the name is present. No other value is used, stored or logged. The environment of Claude desktop's sessions is not read.
  • It reads each session's working folder with lsof, to show the folder in the session's row.
  • From Terminal it reads only each tab's terminal device (tty) and tab title, to name sessions. It does not read window names, because a window name can contain environment variables of the process running in the tab.

What leaves your Mac

The app and the command send nothing anywhere themselves: no analytics, no crash reports, no update checks. The only network use is the claude you installed, which aolangai runs to ask for each account's quota, to check that an account is logged in, and to do the work you delegate, and which you use in the Terminal sessions it opens for you, all under your own login, the same as when you use Claude Code yourself. A link in a run's result opens in your browser only when you click it.

This website

This site sets no cookies. Its home page counts visits with Cloudflare Web Analytics: Cloudflare, which serves this site, adds a script from static.cloudflareinsights.com to that page, and the script reports the page view and how fast the page loaded to Cloudflare, through /cdn-cgi/rum on this site. Cloudflare states that Web Analytics uses no cookies or other storage in your browser and does not fingerprint visitors. This page and the demo do not run that script, and the site loads nothing else from other origins.

The demo runs in your browser on invented accounts and runs; it makes no network request and talks neither to Claude nor to your Mac.

Removing everything

Deleting aolangai.app does not remove what the app wrote outside itself. Remove these yourself:

  • ~/.local/bin/aolangai.
  • ~/.claude/skills/aolangai/, and <config dir>/skills/aolangai/ of each account with its own config dir.
  • ~/Library/Application Support/aolangai/: the data store, profiles/ and the app's other files.

The logins made with claude auth login stay in the Keychain under Claude Code's own entries; remove them with Claude Code or Keychain Access.

Changes and questions

If this policy changes, the new version is published on this page and in the source repository, where you can also open an issue with a question.
